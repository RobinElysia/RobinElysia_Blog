# 技术债务

## 格式约定

每条债务格式：

```
### [YYYY-MM-DD] 简短标题
- **影响范围**：哪些模块受影响
- **债务描述**：当前实现的问题是什么
- **理想状态**：应该怎样
- **预计修复成本**：小（<1h）/ 中（<1d）/ 大（>1d）
- **优先级**：低 / 中 / 高
- **关联 ADR**：（如有）
```

## 当前技术债务

### [2025-07-11] unstable_cache 日期字段类型不一致
- **影响范围**：`src/lib/posts.ts` 全部查询 + 消费方（归档页、详情页、相邻文章）
- **债务描述**：`unstable_cache` 序列化后 Date 变 ISO 字符串（v0.5.0 已踩坑），类型标注仍是 `Date | null`，消费方必须记得 `new Date()`——容易再踩
- **理想状态**：数据访问层返回的日期字段统一标注为 `string | null`（或封装 `toDate()` 辅助函数），从类型层面杜绝误用
- **预计修复成本**：小（<1h）
- **优先级**：中

### [2025-07-11] shiki 主题部分色值硬编码
- **影响范围**：`src/lib/code-theme.ts`
- **债务描述**：字符串/数字色值写了字面量 oklch（如 `oklch(0.38 0 0)`），未走 token 变量——黑白模式正常，但违背"禁止硬编码色值"的规范精神
- **理想状态**：引用 `var(--color-*)` 或提取为命名常量
- **预计修复成本**：小（<1h）
- **优先级**：低

### [2025-07-11] 评论限流为进程内存实现
- **影响范围**：`src/lib/rate-limit.ts`
- **债务描述**：`Map` 滑动窗口仅进程内有效；Vercel serverless 多实例下不共享，限流可被绕过
- **理想状态**：迁移到 Redis（Upstash）或数据库计数；当前单实例部署无碍
- **预计修复成本**：中（<1d）
- **优先级**：低（部署到 serverless 前处理）
