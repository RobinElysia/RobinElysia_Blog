# ADR 0004: 预留——取代 ADR 0003 的决策变更入口

**当前状态**：无待取代的决策。

当 ADR 0003（状态管理方案）需要重大调整时——例如博客功能演进到需要引入 Zustand——在本文件中声明 `supersedes 0003` 并给出新的决策依据。

## 规则

- ADR 一旦写入不可修改内容。需要变更时，新建立即可，旧文档在本文件声明取代。
- 旧文档（0003）保留原内容，仅在顶部加一行 `> **已被 ADR-0004 取代**`。
- 本文件可在未来被 ADR-0005 取代，依此类推。
