## 约束

- **页面容器**：`max-w-4xl`（56rem，约 896px）——**大气布局**，页面不挤在窄条里（2025-07-11 从 max-w-2xl 加宽）
- **正文阅读宽度**：文章正文/评论区 `max-w-3xl`（48rem）居中于容器内——内容区限宽保证长文可读，框架区放宽显大气
- 首页 Hero：`py-24 md:py-32`、花体 `text-7xl md:text-8xl`
- 列表条目：`py-8`、标题 `text-3xl`
- 所有页面水平 padding：`px-6 md:px-8`

## 不使用复杂布局的场景

- 不需要 CSS Grid 做文章列表——`flex flex-col gap-6` 足够
- 不需要 masonry 布局——文章列表不是 Pinterest
- 不需要 sticky 侧边栏——除非侧边栏内容高度超过视口
